Norden UI - Edge Colours
========================
Version {VERSION}

Norden UI wearing Edge UI's colours. Norden's layout, icons, spacing and animations are unchanged;
only its grey ramp is remapped onto Edge UI's, so panels sit at Edge's near-black while headers,
hover states and dividers keep their order above the panel and text lands on Edge's light grey.
Hued accents, the status colours and every opacity value are Norden's own and untouched.

Requires Norden UI. Does nothing on its own. Edge UI is NOT required - this is Norden's art in
Edge's colours, not a merge of the two mods.

INSTALLATION
------------
1. Install Norden UI with the options you want.
2. Install this with your mod manager and work through the installer. It is Norden UI's own
   installer - the same 18 pages, the same 251 options, the same pictures - so PICK THE SAME
   OPTIONS YOU PICKED FOR NORDEN UI. Anything else and you will get recoloured files for menus you
   are not using (harmless) and Norden's original colours on the menus you are (not what you want).
3. Load it AFTER (below) Norden UI so its files win. No plugin, no INI.
4. If you also run Edge UI, pick one: both replace the same menus and whichever loads last wins.

Some options say "No recolour needed: Norden UI's own file for this option already matches Edge's
palette." That option is real and still worth picking to match your Norden choice - it simply has
nothing to add, because Norden and Edge already agree on those colours.

WHAT IT COVERS
--------------
Every loose Norden UI menu that uses its panel grey: inventory, magic, container, barter, crafting,
journal, map, favourites, tween, stats and perks, level-up, dialogue, book, lockpicking, sleep and
wait, training, tutorial, message boxes, loading, start menu, the HUD and its widgets, and Norden's
Wheeler art.

Menus that live inside another mod's BSA (RaceMenu's race menu and bottom bar) are not included in
this version.

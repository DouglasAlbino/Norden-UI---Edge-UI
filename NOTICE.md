# Notice

This repository contains **no art**.

* **Norden UI** by Nithog - https://www.nexusmods.com/skyrimspecialedition/mods/166086
  Every SWF, SVG and image the build touches is his. It is used under Norden UI's permissions
  (modification and release on Nexus, with credit) and is not relicensed. Norden UI's permissions
  forbid uploading its files to other sites, so none of them - original or recoloured - are
  committed here.
* **Edge UI** by Eugene - https://www.nexusmods.com/skyrimspecialedition/mods/130983
  Edge UI's art is never redistributed or modified by this project. It is read only as a colour
  reference (`tools/sample-edge.py`), and the values derived from it live in a git-ignored
  `palette/edge-ui.measured.json` on the build machine. The colour anchors shipped in
  `palette/edge-ui.json` are a small set of numbers describing a palette, not Edge's art.
* **JPEXS Free Flash Decompiler** by Jindra Petrik - used as an external tool, not included.
* **Dynamic Interface Patcher** by Cutleast - the mechanism Norden uses for BSA-bound menus.

The tools in `tools/` are GPL-3.0-or-later; see `LICENSE`.

If either author objects to any part of this project, it will be taken down on request.
